# Capital.com Automation tests

Playwright + Typescript end-to-end automation tests for capital.com

## Tech Stack 
- Playwright
- Typescript

## How to run tests 

Install dependencies:
```bash
npm install
```

Run all tests:
```bash
npx playwright test
```

Run with browser visible:
```bash
npx playwright test --headed
```
